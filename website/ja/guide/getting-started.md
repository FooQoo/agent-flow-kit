# Agent Flow Kit とは

*初めて訪れた方向けに、AFK が何を支えるのか・何をしないのかをわかりやすくまとめたページです。*

> Agent Flow Kit は、AI にまとまった仕事を最後まで任せ切るための軽量プラグインです。
>
> 人間からの依頼をもとに、計画・タスク分け・確認の質問・実行・完了チェック・引き継ぎまでをプロジェクト内の `.afk/` フォルダで支えます。使い慣れた AI エージェントを置き換える必要はありません。

## Agent Flow Kit の役割

**Agent Flow Kit（AFK）** は、Claude Code や Codex といった既存の AI エージェントに追加して使う軽量な仕組み（プラグイン）です。新しいエディタや専用管理画面に乗り換える必要はなく、普段通りの自然な会話のまま、裏側でプロジェクト直下の `.afk/` に計画や進捗を残しながら仕事を進められます。

目指しているのは **「仕事は AI に。主導権はあなたに。」** という役割分担です。

## なぜ必要なのか

今の AI エージェントはコードを書いたり調べたりする能力がとても高い一方、まとまった仕事を任せきろうとすると次の困りごとが起きやすくなります。

- **途中で計画と実装がズレる** — 作業が長くなったり追加要望が入ったりすると、最初の目的や完了条件が会話の奥に流れてしまう。
- **人が決めるべきことまで推測される** — 仕様や好みの分かれる部分を確認しないまま実装が進んでしまう。
- **本当に終わったか証拠が残らない** — 「完了しました」と言われても、決めた条件を全部チェックしたのか後から追いにくい。
- **セッションを閉じると振り出しに戻る** — 翌日や別のツールで続きをやろうとすると、計画や残りの作業を説明し直す必要がある。

## AFK がやってくれること

AFK は 6 つの小さなツール、進め方のガイド（Skill）、会話末尾の進捗表示（Hook）、そしてプロジェクト内の Markdown と SQLite を組み合わせて進行を支えます。

- **依頼を残す** — 最初の依頼だけでなく、途中の追加要望や方針変更も履歴として残します。
- **計画とタスクを整理する** — 大きな仕事を順番・前提関係・完了条件付きのタスクに分けます。
- **迷うときだけ質問する** — 意図が曖昧なとき・好みの分かれる仕様・元に戻しにくい操作・範囲が広がるときだけ確認を求めます。
- **完了条件をチェックする** — 最初に決めた計画が勝手に変わらないよう保護し、完了条件を全部確認して結果メモを書くまで完了にしません。
- **会話の最後に進捗を出す** — わざわざ「今どこまで？」と聞かなくても、保存データから自動で進捗を表示します。
- **翌日や別ツールへ引き継ぐ** — 状態をプロジェクト内の `.afk/` に残し、引き継ぎメモで別セッションから続きを再開できます。

## 実際の使い心地

利用者が特別なコマンドや JSON を書く必要はありません。普段通り自然な言葉で話しかけます。

```text
あなた: 検索機能を改善して、テストも追加してください。まず計画を見せて。
AI:     5つのタスクで計画を作成しました。着手前に1点確認させてください。
        検索結果の並び順は関連度順と新着順のどちらにしますか？
あなた: 関連度順でお願いします。そのまま進めて。
AI:     計画を更新し、順番に実装を進めます。
[AFK]   検索機能の改善 [Doing] · ██████░░░░ 3/5 complete (60%)
```

*※ 上記は利用イメージです。途中の要望追加や引き継ぎを含む詳しい流れは [最初の仕事を任せる](/ja/guide/quickstart) を参照してください。*

## AFK がやらないこと

軽さと普段の環境との共存を優先するため、AFK は以下を行いません。

- 独自の AI モデルを提供する
- 複数のエージェントを自動起動・並列管理するランタイムを持つ
- 専用の Web 管理画面を用意する（Agent Board や Agent Project の導入も不要です）
- 特定の開発手法を押し付ける

AFK は既存エージェントの仕事の進め方を支える補助輪であり、AI の判断の正しさや完全な自律完遂を保証するものではありません。

## 対応しているエージェント

- **Claude Code** — Git マーケットプレイスからプラグインとして導入できます。
- **Codex** — Git マーケットプレイスからプラグインとして導入できます。
- **その他の stdio MCP クライアント**（Antigravity など）— 手動の MCP + Skill 設定で利用できます。

導入手順とクライアントごとの違いは [インストール](/ja/guide/installation) を参照してください。
