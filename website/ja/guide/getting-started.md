# Agent Flow Kit とは

*初めて訪れた方向けに、AFK が何を支えるのか・何をしないのかを短くまとめたページです。*

> Agent Flow Kit は、AI の仕事の遂行を支える軽量なハーネスです。
>
> 人間からの依頼を起点に、計画、タスク分解、質問、実行、完了までの進行を支援します。使い慣れた AI エージェントを置き換えることなく、仕事を任せるための仕組みを追加します。

## What is AFK?

**Agent Flow Kit（AFK）** は、Claude Code や Codex といった既存の AI エージェントに Plugin として追加する **Workflow Harness** です。新しい実行環境や専用管理画面への移行を求めず、普段通りの自然言語の会話のまま、プロジェクト直下の `.afk/` に構造と状態を保持しながら仕事を進められます。

タグラインは **Delegate work. Stay in control.**（仕事を任せ、主導権は保つ）です。

## Why AFK?

現在の AI エージェントはコード記述や調査・テスト実行に高い能力を持っていますが、まとまった仕事を任せきろうとすると次の問題が起きやすくなります。

- **計画や目的が途中で抜け落ちる** — 作業が長くなるほど、当初の要件や完了条件が見落とされやすい。
- **人間が決めるべき事項まで推測される** — 仕様や選好を確認しないまま実装が進んでしまう。
- **本当に完了したか分かりにくい** — すべての要件が検証されたか、人間が改めて確認する必要がある。
- **セッションをまたぐと文脈が失われる** — 新しい会話を開くたびに、計画・決定事項・残タスクを説明し直す必要がある。

## What AFK does

AFK は 6 つの状態付き MCP ツール、簡潔な Skill、軽量なライフサイクル Hook、そしてプロジェクト内の Markdown + SQLite を組み合わせて進行を支えます。

- **依頼の記録** — 初回の依頼だけでなく、途中の追加依頼や方向修正も履歴として残します。
- **計画とタスク分解** — 仕事を順序・依存関係・完了条件付きのタスクに整理します。
- **必要なときだけの質問** — 意図不明・人間の選好・不可逆な操作・依頼範囲の拡大が必要な場面だけ確認を求めます。
- **進行支援と完了検証** — タスクの実行履歴を記録し、`## Acceptance` の全項目確認と `## Result` の記録を完了条件にします。
- **ターン末尾の進捗報告** — Stop Hook により、追加のモデル推論を要求せず現在状況を自動で報告します。
- **セッションを超えた継続** — 状態をプロジェクト内の `.afk/` に保存し、引き継ぎメモ（handoff）で別セッションから再開できます。

## How it feels

利用者が MCP ツールを直接叩く必要はありません。普段通り自然言語で話しかけます。

```text
あなた: 検索機能を改善して、テストも追加してください。まず計画を見せて。
AI:     5つのタスクで計画を作成しました。着手前に1点確認させてください。
        検索結果の並び順は関連度順と新着順のどちらにしますか？
あなた: 関連度順でお願いします。そのまま進めて。
AI:     計画を更新し、順番に実装を進めます。
[AFK]   AFK · 検索機能の改善 [Doing] · 3/5 complete · Next: テストの追加
```

*※ 上記は利用イメージです。途中依頼や再開を含む詳しい流れは [クイックスタート](/ja/guide/quickstart) を参照してください。*

## What AFK does not do

軽量さと既存環境との共存を優先するため、AFK は以下を提供しません。

- 独自の LLM やモデル実行基盤
- エージェントの起動・並列実行ランタイム
- 専用の Web 管理画面（Agent Board や Agent Project の導入も不要です）
- 特定のソフトウェア開発方法論の強制

AFK は既存エージェントの仕事の進め方を拡張するハーネスであり、モデル自体の推論や完全な自律完遂を保証するものではありません。

## Supported agents

- **Claude Code** — Git プラグインマーケットプレイス経由で導入（MCP・Skill・Hooks）。
- **Codex** — Git プラグインマーケットプレイス経由で導入（MCP・Skill・Hooks）。
- **その他の stdio MCP クライアント**（Antigravity など）— 手動の stdio MCP + Skill 設定で利用可能。

具体的な導入手順とクライアント間の違いは [インストール](/ja/guide/installation) を参照してください。
