# クイックスタート

[AFK をインストール](./index.md)し、作業先のプロジェクトで新しいエージェントセッションを開きます。

## 計画を頼む

Claude Code では `/agent-flow-kit:afk` に続けて、Codex では `$agent-flow-kit:afk` を選んで、次の依頼を送ります。

> サンプルの JSON と、項目を確認するテストを作る計画を立てて。実装を始める前に計画を見せて。JSON に入れる項目は聞いて決めて。

依頼と計画はプロジェクトの `.afk/` に保存されます。質問が来たらチャットで答え、タスクと完了条件を確認します。

## 作業を始めて、途中で調整する

計画を確認したら「着手して」と伝えます。途中で条件が増えたら、そのままチャットで伝えます。

> 名前が空なら検証に失敗するケースも足して。

エージェントは残りの計画を更新します。何を検証したかは、`.afk/tasks/` にあるタスクの `## Result` で確認できます。

## 引き継ぎメモを残して再開する

Claude Code では `/agent-flow-kit:afk handoff` を実行します。Codex では `$agent-flow-kit:afk` を選んで `handoff` と送ります。

作業中のセッションが停止したら、同じプロジェクトで新しいセッションを開き、プラン番号を指定して再開を頼みます。引き継ぎメモには検証済みの内容と次の作業が残っています。
