# 最初の仕事を任せる

*[インストール](/ja/guide/installation) を終えた方が、自然な会話で 1 つの仕事を依頼から完了・引き継ぎまで体験するためのガイドです。*

**前提:** Claude Code または Codex に AFK を導入済みで、編集してよいサンプルプロジェクトを開いていること。

## 一連の流れ（会話イメージ）

依頼から計画、質問、実行、途中の要望追加、完了までの流れは次のようになります。

```text
あなた: 検索機能を改善して、テストも追加してください。
AI:     計画を作成しました。
        1. 既存実装の調査
        2. 検索仕様の整理
        3. 検索ロジックの実装
        4. テストの追加
        5. 完了条件の検証
AI:     検索結果の並び順は関連度順と新着順のどちらにしますか？
[AFK]   AFK · 検索機能の改善 [待機中] · 0/5 完了 · 回答待ちの質問 1 件

あなた: 関連度順でお願いします。そのまま進めて。
AI:     回答を反映して計画を更新し、検索ロジックまで実装しました。
[AFK]   AFK · 検索機能の改善 [進行中] · 3/5 完了 · 次: テストの追加

あなた: 検索結果が0件の場合の表示も改善して。
AI:     追加依頼を記録し、残りの計画と完了条件を更新します。
[AFK]   AFK · 検索機能の改善 [進行中] · 3/6 完了 · 次: テストの追加

あなた: 続けて。
AI:     実装・テスト・完了条件の確認がすべて終わりました。
[AFK]   AFK · 検索機能の改善 [完了] · 6/6 完了 · すべての作業が完了しました
```

*※ 上記は流れを掴むためのイメージです。`[AFK]` 行は会話の最後に自動で表示される進捗であり、AI の発言とは別です。毎回途中で指示を挟む必要はなく、タスク数や確認回数は依頼内容によって変わります。*

## 7 つのステップ

### 1. 依頼する

プロジェクトで新しいセッションを開き、普段通りの言葉でやりたいことを伝えます。Claude Code なら `/agent-flow-kit:afk` に続けて入力し、Codex なら `$agent-flow-kit:afk` を選んで送信します。特別な書式は不要で、依頼は `.afk/requests/` に残ります。

### 2. 計画を立てる

AI が依頼を順番付きのタスクに分け、「何ができていれば完了か（`## Acceptance`）」を `.afk/plans/` と `.afk/tasks/` に書き出します。「まず計画だけ立てて」と頼んだ場合は待機状態のまま止まり、勝手に実装を始めません。

### 3. 迷う点だけ確認する

人間の意図・好み・元に戻しにくい操作・範囲の広がりなど、人が決めるべき点だけ AI が `.afk/questions/` に質問を用意してチャットで確認します。迷う点がなければこの工程は飛ばされます。

### 4. 順番に進める

開始が許可されると、AI が前提順序どおりに作業を進め、確認した証拠を各タスクファイルの `## Result` に書き残します。作業の途中で新たな疑問が出た場合も、その場で質問できます。

### 5. 途中で要望を足す・方向を変える

作業中に要件が増えたり方針が変わったりしたら、そのままチャットで伝えます。AFK が追加の依頼を記録し、すでに終わったタスクの記録は消さずに残したまま、残りの計画だけを新しい版として更新します。

*※ 実行中の割り込みタイミングは、利用しているクライアントの仕様に従います。*

### 6. 条件を確かめて完了する

すべてのタスクが終わり、計画全体の完了条件チェックと結果メモの記載が揃うと完了になります。確認された内容は `.afk/tasks/` や `.afk/plans/` からいつでも読み返せます。

### 7. 別セッションへ引き継ぐ

作業を途中で止めて翌日や別セッションへ引き継ぎたいときは、Claude Code なら `/agent-flow-kit:afk handoff`、Codex なら `$agent-flow-kit:afk` を選んで `handoff` と送ります。

次のセッションで同じプロジェクトを開き、「前回の作業を続けて」と伝えれば、保存された計画・進捗・引き継ぎメモを読み込んで続きから再開できます。

## よく使う頼み方の例

| 場面 | 伝え方の例 | 動き方 |
| --- | --- | --- |
| 計画だけ見たい | 「まず実装計画だけ立てて」 | 実装を勝手に始めず、待機状態で止めます。 |
| 計画を実行したい | 「その計画で進めて」 | 開始許可を出し、タスクを順番に実行します。 |
| そのまま進めてほしい | 「この機能を実装してテストして」 | 不要な承認を挟まず、迷う点だけ質問して進めます。 |
| 途中で変更したい | 「やっぱり新着順にして、0件表示も直して」 | 追加依頼を記録し、終わった分を残して残りを再計画します。 |
| 続きから再開したい | 「前回の作業を続けて」 | 保存された計画と引き継ぎメモから再開します。 |
| 状況を知りたい | 「今どこまで進んでいる？」 | 進捗・未回答の質問・次の作業を答えます（普段は会話の最後にも自動表示）。 |
