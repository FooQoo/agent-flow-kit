# 最初の仕事を任せる（Quickstart）

*[インストール](/ja/guide/installation) を終えた方が、自然言語で 1 つの仕事を依頼から完了・再開まで体験するためのガイドです。*

**前提条件:** Claude Code または Codex に AFK を導入済みで、変更してよいサンプルプロジェクトを開いていること。

## 一連の流れ（会話例）

依頼から計画、質問、実行、途中依頼、完了までの流れは次のようになります。

```text
Human: 検索機能を改善して、テストも追加してください。
AI:    計画を作成しました。
       1. 既存実装の調査
       2. 検索仕様の整理
       3. 検索ロジックの実装
       4. テストの追加
       5. 完了条件の検証
AI:    検索結果の並び順は関連度順と新着順のどちらにしますか？
[AFK]  AFK · 検索機能の改善 [Backlog] · 0/5 complete · 1 question waiting

Human: 関連度順でお願いします。そのまま進めて。
AI:    回答を反映して計画を更新し、検索ロジックまで実装しました。
[AFK]  AFK · 検索機能の改善 [Doing] · 3/5 complete · Next: テストの追加

Human: 検索結果が0件の場合の表示も改善して。
AI:    追加依頼を記録し、計画と完了条件を更新します。
[AFK]  AFK · 検索機能の改善 [Doing] · 3/6 complete · Next: テストの追加

Human: 続けて。
AI:    実装・テスト・完了条件の検証が完了しました。
[AFK]  AFK · 検索機能の改善 [Done] · 6/6 complete · Plan complete
```

*※ 上記は説明用の例です。`[AFK]` 行は会話ターン末尾の Stop Hook による報告イメージであり、モデルの発言とは別です。毎回途中で入力する必要はなく、タスク数や確認回数は依頼内容やクライアントの挙動によって変わります。*

## ステップごとの流れ

### 1. Request（依頼する）

プロジェクトで新しいセッションを開き、普段通りの言葉でやりたいことを伝えます。Claude Code では `/agent-flow-kit:afk` に続けて入力し、Codex では `$agent-flow-kit:afk` を選んで送信します。特別な書式は不要で、依頼は `.afk/requests/` に記録されます。

### 2. Plan（計画する）

AI が依頼を順序と完了条件（`## Acceptance`）付きのタスクに分解し、`.afk/plans/` と `.afk/tasks/` に整理します。「まず計画だけ立てて」と頼んだ場合は `Backlog` 状態で待機し、勝手に実装を開始しません。

### 3. Clarify（不明点を解消する）

人間の意図・選好・不可逆な操作・依頼範囲の判断が必要な場合のみ、AI が `.afk/questions/` に質問を用意してチャットで確認します。不明点がなければこの工程は省略されます。

### 4. Execute（実行する）

実行が許可されると、AI が前提順序に沿ってタスクを進め、完了条件を検証した結果を各タスクファイルの `## Result` に記録します。作業の途中で新たな疑問が出た場合も、同様に質問できます。

### 5. Adapt（追加・方向修正する）

作業の途中で要件が増えたり方針が変わったりしたら、そのままチャットで伝えます。AFK が追加依頼を記録し、完了済みタスクは証跡として残したまま、残りの計画と完了条件を新しいリビジョンで更新します。

*※ 実行中の割り込みタイミングや反映境界は、利用するクライアントの仕様に従います。*

### 6. Complete（検証して完了する）

すべてのタスクが完了し、プラン自身の `## Acceptance` の全項目確認と `## Result` の記録が揃うとプランが完了（`Done`）になります。検証結果は `.afk/tasks/` や `.afk/plans/` からいつでも確認できます。

### 7. Resume（セッションをまたいで再開する）

別のセッションへ引き継ぎたいときは、Claude Code なら `/agent-flow-kit:afk handoff`、Codex なら `$agent-flow-kit:afk` を選んで `handoff` と送ります。

次のセッションで同じプロジェクトを開き、「前回の AFK の作業を続けて」と伝えれば、保存された計画・状態・引き継ぎメモを読み込んで続きから再開できます。

## その他の会話例

| 利用パターン | 依頼例 | 挙動 |
| --- | --- | --- |
| 計画のみ | 「まず実装計画だけ立てて」 | 実装を勝手に開始せず、`Backlog` として保持します。 |
| 計画を実行 | 「その計画で進めて」 | 実行指示を受けて `Todo` へ進め、タスクを順次実行します。 |
| 直接実行 | 「この機能を実装してテストして」 | 不要な一律承認は求めず、不明点がある場合のみ質問します。 |
| 追加・変更 | 「やっぱり新着順にして、0件表示も直して」 | 追加依頼を記録し、影響範囲を整理して残タスクを再計画します。 |
| 再開 | 「前回の作業を続けて」 | 保存されたプランと引き継ぎメモを読み、継続可能なタスクから再開します。 |
| 状況確認 | 「今どこまで進んでいる？」 | 進捗・未回答の質問・次の作業を取得します（Hook 有効時はターン末尾にも自動表示）。 |
